# Array Max

Implement `Max`, which returns the maximum value in a non-empty array of integers.

Your postcondition must establish that the result appears in the array and
that no element of the array exceeds it. You will need a loop invariant to
make this provable — the postcondition is not provable from the signature
alone.

## Task

Fill in the body of `Max` so that it verifies. You may add local variables,
a loop, and loop invariants, but the method signature (including its `requires`
and `ensures` clauses) is fixed.
